# Rumbo — Aplicación web

Interfaz web de Rumbo (React + Vite + TypeScript). Habla solo con el **API Gateway** (`http://localhost:8080`), nunca directamente con los microservicios.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # compila a dist/
```
